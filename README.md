# ✅ TaskFlow

Aplicação web de gerenciamento de tarefas desenvolvida com **HTML, CSS e JavaScript**.

## 🚀 Funcionalidades

- ➕ Adicionar tarefas
- ✅ Concluir e reabrir tarefas
- 🗑️ Excluir tarefas
- 🔎 Filtrar tarefas
- 📊 Contador de tarefas
- 📈 Barra de progresso
